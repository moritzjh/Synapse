# Welcome to Synapse 👋

Synapse is **notes + flashcards + knowledge graph** in one app – everything stays on your machine as plain Markdown.

## Write notes, get flashcards

Flashcards are written right inside your notes:

What does Synapse store notes as? >> Plain Markdown files in your vault

Spaced repetition :: Reviewing at growing intervals, just before you would forget

Synapse schedules cards with the {{FSRS}} algorithm, the same one modern {{Anki}} uses.

Three ways to make a card >>
- `Question >> Answer`
- `Term :: Definition` (both directions)
- `{{cloze}}` gaps

## Things to try

- [ ] Hover a block and drag the `⋮⋮` handle, or click it to *turn into* another block
- [ ] Type `/` for the block menu – headings, to-dos, tables, databases, diagrams, formulas
- [ ] Open the **Graph** and watch [[Cell]], [[Energy]] and [[Algorithms]] cluster by topic
- [ ] Press **Study** in the sidebar – or the cards button next to any folder
- [ ] Import your Anki decks with the ⤓ button above the note list

> [!tip]
> Notes that are *about the same thing* get connected automatically by a local AI model – no cloud, no API key.
